[ENGLISH]
• Navigate: Use up/down Arrows or Mouse. Use Tab for Switch Panels.
• For Open: Double-Click on mouse or Hit Enter key. By Mobile: Press and Hold For 3 Second.
• For make New File: Press Shift+F4. For Search: Press Ctrl+F or Open Commands Menu.
• For File Download in Right menu Select Drive... Alt-F2 then Select PC C: Drive, Copy file to your PC C: Drive by press on F5 copy
• For Sorting Files by Name: Left/Right Menu Select sort by names.

• ნავიგაციისთვის: გამოიყენეთ ზევით/ქვევით ისრები ან მაუსი. გამოიყენეთ Tab ღილაკი პანელის ასარჩებად.
• გახსნისთვის: ორჯერ დააწკაპუნეთ მაუსის ან დააჭირეთ Enter ღილაკს. მობილურით: დააჭირეთ და დაიკავეთ 3 წამი.

[РУССКИЙ]
• Навигация: используйте стрелки вверх/вниз или мышь. Используйте Tab для переключател панелей.
• Для открытия: дважды щелкните мышью или нажмите клавишу Enter. На мобильном телефоне: нажмите и удерживайте в течение 3 секунд.
• Для создания нового файла: нажмите Shift+F4. Для поиска: нажмите Ctrl+F или откройте меню Commands.
• Для загрузки файла в правом меню выберите Drive... затем выберите PC C: Drive, скопируйте файл на свой компьютер PC C: Drive, нажав F5 copy
• Для сортировки файлов по имени: Меню слева/справа. Выберите сортировку по имени.
